検証方法と注意事項

まず各作品の1〜4マスを確認してください。4マス完成時だけ完成画像とアニメーションが表示されます。完成後は画面下の絵をタップすると大きく表示できます。アニメーションを「オフ」にすると動きを抑制します。画面幅、スクロール、画像の欠け、ページ遷移も確認してください。

本サイトは開発検証専用です。テストデータは実際の学習履歴ではありません。実機確認と公開承認が得られるまで本番v1.3は維持します。

GitHub Pagesで公開する場合、この確認ページと原画は一般公開されます。患者・児童などの実データは追加しないでください。
